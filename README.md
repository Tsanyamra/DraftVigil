# DraftVigil

Decentralized workflow manager leveraging event-driven architecture, scalable API-gateway, and fault-tolerant engine for seamless distributed execution.

DraftVigil is built to be simple and practical, focusing on doing one thing well.

**Why DraftVigil?**

- Decentralized workflow manager leveraging event-driven
- architecture, scalable API-gateway, and fault-tolerant
- engine for seamless distributed execution

## Key Features

- Decentralized workflow manager leveraging event-driven

- engine for seamless distributed execution

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/DraftVigil.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DraftVigil is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
